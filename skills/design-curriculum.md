# Design Curriculum

Use this skill to turn `profile.md` into `learn/<instance>/curriculum.md`.

## Inputs

- `learn/<instance>/profile.md`
- `templates/curriculum-template.md`

## Workflow

1. Extract the learner goal, current level, constraints, and preferred learning approach.
2. Choose a lesson sequence that fits the available time.
3. Assign stable lesson IDs.
4. Write teacher-facing lesson units using every required field from the template.
5. Include safety, boundary, or verification rules when the topic requires them.
6. Make the first lesson easy to start and the final lesson useful for review or next-step planning.

## Quality Bar

- Lessons must be teachable without additional planning.
- Practice must produce observable evidence.
- Assessments must check the lesson objective.
- Next links must make the course feel cumulative.

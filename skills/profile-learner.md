# Profile Learner

Use this skill to interview the learner and create `learn/<instance>/profile.md`.

## Inputs

- User's requested learning topic, if already known.
- Existing learner answers, if provided.
- `templates/profile-template.md`.

## Workflow

1. Ask the learner's preferred language near the beginning and use it for profiling unless the user requests otherwise.
2. Ask only the missing profiling questions needed to define a useful first course.
3. Keep language plain and nonjudgmental.
4. Record unknowns explicitly instead of inventing details.
5. Confirm the proposed direction with the learner when the scope is ambiguous or high-impact.
6. Write the completed profile to `learn/<instance>/profile.md`.

## Output Requirements

The profile must include:

- topic and motivation
- preferred language
- current level and relevant experience
- target outcome and success scene
- included and excluded scope
- schedule
- learning approach
- feedback preferences
- progress tracking
- first session recommendation

# Review Progress

Use this skill to summarize progress and recommend next steps for an active learning instance.

## Inputs

- `learn/<instance>/profile.md`
- `learn/<instance>/curriculum.md`
- `learn/<instance>/sessions.md`

## Workflow

1. Compare completed session evidence with the learner goal.
2. Identify completed lessons, strengths, weak points, and repeated misconceptions.
3. Recommend review, continuation, curriculum adjustment, or next course planning.
4. Keep recommendations grounded in logged evidence.

## Output

Provide:

- current progress summary
- evidence-based strengths
- evidence-based weak points
- next lesson or review recommendation
- curriculum adjustment notes, if needed

# Curriculum Template

Save completed curricula as `learn/<instance>/curriculum.md`.

## Curriculum Header

```text
# Curriculum

## Course Goal

## Learner Context

## Teaching Principles

## Safety Or Boundary Rules

## Lesson Sequence
```

## Lesson Structure

Every lesson must use a stable ID and include the fields below.

```text
### <lesson-id>: <title>

**ID**:

**Title**:

**Objective**:

**Core Concepts**:

**Required Explanation**:

**Teaching Guidance**:

**Example/Scenario**:

**Practice**:

**Assessment**:

**Common Misconceptions**:

**Progress Evidence**:

**Next Link**:
```

## Field Guidance

- `ID`: stable identifier such as `L01`, `L02`, or `module-1-lesson-1`.
- `Title`: learner-facing lesson name.
- `Objective`: what the learner should be able to do after the lesson.
- `Core Concepts`: terms, principles, or patterns the teacher must cover.
- `Required Explanation`: explanation that must be included before practice.
- `Teaching Guidance`: pacing, scaffolding, accessibility, and personalization notes.
- `Example/Scenario`: concrete context for the lesson.
- `Practice`: learner action, exercise, role-play, problem, or project step.
- `Assessment`: how to check understanding.
- `Common Misconceptions`: likely mistakes and how to correct them.
- `Progress Evidence`: what to record in `sessions.md`.
- `Next Link`: how this lesson prepares for the next lesson.

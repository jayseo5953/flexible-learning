# Profile Template

Use this template to interview a learner before creating a personalized course. Ask in plain language. The goal is not to test the learner; it is to discover goals, constraints, preferences, and a realistic first learning scope.

Do not overwrite this template. Save the completed learner profile as `learn/<instance>/profile.md`.

## 1. Start

Explain the purpose and lower the pressure:

```text
I will ask a few questions so we can build a course that fits you.
There are no right answers. If you do not know, "I am not sure" is fine.

We will define:
- what you want to learn
- why you want to learn it
- which language you prefer for the course
- what success should look like
- how much time you can spend
- how you prefer to learn
- how progress should be checked
```

## 2. Topic And Motivation

Ask:

```text
What do you want to learn?
Why do you want to learn it?
What language should the course use?
```

Examples:

- a language skill
- investing basics
- programming
- design tools
- writing
- interview preparation
- a physical routine
- a new hobby

## 3. Target Outcome

Turn broad goals into observable actions.

Ask:

```text
When this course is finished, what should you be able to do?
What would make you feel that the course worked?
```

Record a concrete success scene, not only a broad wish.

## 4. Current Level

Ask for self-assessment:

```text
How much do you know about this topic now?

1. Complete beginner
2. I have only heard a little about it
3. I have learned the basics before
4. I have tried it on my own
5. I can do the basics and want to improve
```

Ask for recent related experience:

- videos watched
- books or articles read
- classes taken
- projects tried
- failed attempts
- concepts already known

Use a short diagnostic prompt:

```text
Can you explain this topic in about three sentences using what you know now?
If not, "I am not sure" is fine.
```

During diagnosis:

- do not respond as if wrong answers are failures
- separate known, unknown, and confusing areas
- simplify the diagnostic for beginners
- ask for concrete examples or artifacts from experienced learners

## 5. Scope And Schedule

Ask:

```text
How long do you want to learn?
How many sessions per week can you do?
How long can each session be?
What must be included?
What should be excluded?
```

Record:

```text
Duration:
Frequency:
Session length:
Include:
Exclude:
```

## 6. Learning Style

Ask:

```text
How do you prefer to learn?
```

Examples:

- follow examples
- learn by doing
- hear the explanation first
- use quizzes or games
- role-play real situations
- build a small project
- explain the idea back in your own words

Ask about feedback:

```text
When something is wrong, do you prefer immediate correction or a summary at the end?
When you are stuck, what kind of help is best?
```

Help options:

- hint
- sample answer
- step-by-step explanation
- easier exercise
- repeated similar practice
- diagram or table

## 7. Personalization

Ask:

```text
What information would help tailor examples and practice to you?
What topics, contexts, or examples would make practice more interesting?
What topics should be avoided?
```

Do not request sensitive personal information. Do not infer details the learner did not provide.

## 8. Progress Tracking

Ask:

```text
How should progress be shown?
How often should check-ins happen?
```

Default tracking:

- short summary at the end of each session
- periodic review
- learned concepts
- practice completed
- strengths
- difficulties
- recurring weak points
- next review item
- progress against the learner goal

## 10. Readiness Checklist

Before building the curriculum, confirm:

- topic is clear
- motivation is clear
- success scene is observable
- current level is roughly known
- preferred language is recorded
- schedule is realistic
- include and exclude scope are defined
- learning preferences are recorded
- feedback preferences are recorded
- progress tracking is defined
- first session direction is known

# Sessions Template

Save session logs as `learn/<instance>/sessions.md`. Treat the file as append-only learner history. Add new entries at the end and avoid rewriting older records except to correct factual logging errors.

## Session Log

```text
# Sessions

## Instance
- Active curriculum:
- Started:
- Current lesson:
- Last updated:

## Progress Snapshot
- Completed lessons:
- Current strengths:
- Current weak points:
- Next review:

## Entries
```

## Entry Format

```text
### <date> - <lesson-id>: <lesson title>

**Session Goal**:

**What Happened**:

**Learner Response/Evidence**:

**Assessment**:

**Strengths**:

**Difficulties**:

**Corrections Or Clarifications**:

**Progress Update**:

**Next Step**:
```

## Rules

- Use lesson IDs from `curriculum.md`.
- Record evidence, not only impressions.
- Preserve uncertainty when the learner is unsure.
- Keep the next step specific enough to start the following session.
- If the curriculum changes, append a note explaining why.
